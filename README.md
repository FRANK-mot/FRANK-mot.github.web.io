## Getting Started
These instructions help you run the site locally.

Prerequisites
- Git
- Node.js and npm (if using a static-site generator or bundler)
- Ruby + Bundler (if using Jekyll)

Clone the repo
```bash
git clone https://github.com/FRANK-mot/FRANK-mot.github.web.io.git
cd FRANK-mot.github.web.io
```

If it's plain static files
```bash
# open index.html in the browser or run a quick server:
python3 -m http.server 8000
# then open http://localhost:8000
```

If it's Jekyll
```bash
bundle install
bundle exec jekyll serve
# open http://localhost:4000
```

If it's a Node-based generator (example Eleventy)
```bash
npm install
npm run dev
# open the dev URL shown in the terminal
```

## Deployment (GitHub Pages)
- For a user/organization site the repo name must be `FRANK-mot.github.io` and the site will be served from the default branch (usually `main`).
- For a project site you can use the `gh-pages` branch or the `docs/` folder on `main`.
- In GitHub: Settings → Pages → set the source branch/folder and save.

If you're using a static site generator, build the production files and push the output to the branch configured for Pages (or use `gh-pages` npm package).
